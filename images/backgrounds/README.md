# 🖼️ 背景轮播壁纸存放说明

把你的壁纸图片放入此目录（`images/backgrounds/`）即可在主页自动轮播显示。

---

### 📐 推荐规格与参数

| 项目 | 推荐标准 | 说明 |
| :--- | :--- | :--- |
| **分辨率** | **1920 × 1080** (1080P) 或 **3840 × 2160** (4K) | 横版壁纸（16:9 比例），铺满电脑屏幕效果最佳 |
| **图片格式** | **`.webp`** 或 **`.jpg` / `.jpeg`**（也可支持 `.png`） | 推荐使用 `.webp` 或 `.jpg`，加载速度快、占用内存小 |
| **单张大小** | **500KB ~ 2MB** 左右 | 避免图片过大（如超过 10MB）导致加载缓慢 |
| **视觉风格** | **深色系、风景、摄影、极简、动漫、赛博朋克等** | 页面会自动添加 40% 柔和暗色遮罩与噪点纹理，保证时钟、天气和播放器文字始终清晰易读 |

---

### 📝 文件命名与配置方式

#### 默认预设文件名（即放即用）：
直接将图片命名为以下名称放入本文件夹：
- `bg1.jpg`
- `bg2.jpg`
- `bg3.jpg`
- `bg4.jpg`
- `bg5.jpg`

#### 自定义文件名或轮播时间：
在 `js/main.js` 顶部修改 `BACKGROUNDS` 列表和 `BG_INTERVAL`（切换间隔）：
```javascript
const BACKGROUNDS = [
  'images/backgrounds/我的壁纸1.webp',
  'images/backgrounds/我的壁纸2.jpg',
  'images/backgrounds/夜景.png',
];

const BG_INTERVAL = 8000; // 轮播间隔（毫秒），8000 = 8秒切换一次
```
